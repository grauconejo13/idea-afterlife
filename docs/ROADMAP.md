# Roadmap

## Milestone 0 — Foundation

- Product definition and terminology
- Permission and attribution principles
- React/Vite scaffold
- Sample domain data
- Contribution and decision documentation

## Milestone 1 — Public archive prototype

- Editorial landing page
- Searchable and filterable idea gallery
- Idea detail view
- Permission badges
- Responsive navigation
- Mock “Leave an idea behind” form
- Empty, loading, and error states
- Accessibility and responsive QA

## Milestone 2 — Accounts and persistence

- Authentication
- Creator profiles
- Database-backed ideas and drafts
- Save and publish workflow
- Image upload with limits
- Ownership and edit authorization

## Milestone 3 — Revivals and lineage

- Propose or publish a revival
- Creator acknowledgement
- Lineage visualization
- Revival updates
- Reporting and moderation baseline

## Milestone 4 — Community and media

- Video support
- Collections and bookmarks
- Collaboration requests
- Notifications
- Moderation tooling
- Search indexing and sharing metadata
