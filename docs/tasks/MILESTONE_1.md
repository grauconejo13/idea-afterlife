# Milestone 1 — Public archive prototype

## Goal

Deliver a convincing, responsive prototype that communicates the Idea Afterlife concept without requiring a backend.

## Tasks

### IA-101 — Establish visual direction

- Define typography, palette, spacing, and motion rules
- Avoid literal cemetery clichés that make failed work feel morbid
- Preserve a reflective editorial tone

### IA-102 — Build discovery page

- Add hero and concept explanation
- Render sample idea cards
- Add category, status, and permission filters
- Add keyword search
- Include meaningful zero-results state

### IA-103 — Build idea detail experience

- Present story, reason it stalled, remains, lessons, and last wish
- Display creator, dates, tags, and permissions
- Reserve a clear area for lineage and revivals

### IA-104 — Build mocked submission flow

- Divide the form into understandable sections
- Require permission selection
- Support local media previews only
- Validate required inputs and provide completion feedback

### IA-105 — Quality pass

- Keyboard navigation and visible focus
- Semantic headings and form labels
- Mobile, tablet, and desktop layouts
- Reduced-motion support
- Production build verification

## Definition of done

- All prototype routes work without a backend
- Sample data can be replaced without component rewrites
- Permission intent is visible on every idea
- No ownership-transfer language appears
- `npm run build` passes
