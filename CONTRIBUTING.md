# Contributing

## Workflow

1. Create a focused branch from `main`.
2. Keep changes aligned to one milestone or issue.
3. Run `npm run build`.
4. Explain user impact and validation in the pull request.

## Product principles

- Preserve creator credit.
- Make permissions explicit before encouraging reuse.
- Treat failed work with curiosity, not ridicule.
- Keep an idea's original history intact when it is revived.
- Do not imply legal ownership transfer through a UI action.

## Code conventions

- Prefer small, accessible React components.
- Keep mock content in `src/data`.
- Avoid adding dependencies without documenting the reason.
- Update `docs/DECISIONS.md` when a choice constrains future work.
