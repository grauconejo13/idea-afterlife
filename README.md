# Idea Afterlife

> Good ideas do not have to die with their first attempt.

Idea Afterlife is a place to document unrealized, abandoned, failed, or nearly forgotten ideas so other people can learn from them, collaborate, remix them, or give them a second life.

## Current status

Milestone 1 — public archive prototype, complete.

The app includes an editorial landing page, searchable and filterable archive, idea detail pages, explicit permission badges, responsive navigation, and a local-only submission preview. A related-idea flow carries an origin record into the prototype submission experience so a future revival can keep its lineage visible. Authentication, persistence, real uploads, and publishing remain deferred to Milestone 2.

## Core loop

1. A creator leaves an idea behind and explains its history.
2. They attach remains such as images, video, sketches, research, or prototype links.
3. They choose clear reuse and collaboration permissions.
4. Another person discovers the idea and proposes or publishes a revival.
5. The original and every revival remain connected through visible lineage.

## Local development

```bash
npm install
npm run dev
```

## Product language

| Term | Meaning |
| --- | --- |
| Idea | An original unrealized or discontinued concept |
| Remains | Supporting media, notes, research, or prototypes |
| Last wish | What the creator hopes happens next |
| Revival | A continuation, remix, or reinterpretation |
| Lineage | The visible relationship between an idea and its revivals |
